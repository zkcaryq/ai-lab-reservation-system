## 1. 项目背景

本项目为"AI 智能实验室预约系统"（FastAPI + PostgreSQL 后端）配套的企业知识库原始语料。
文档内容覆盖：10 间实验室、40 类设备、18 项管理制度、业务表格与 OCR 测试原件，
全部事实数据与 2026-10-20 开发数据库只读快照及后端业务代码保持一致。

## 2. 事实数据来源（优先级从高到低）

1. 开发数据库 `ai_lab_db.app` 只读查询快照（labs / equipments 表，2026-10-20）；

   `lab_services.py`、`equipment_services.py`、`reservation_services.py`、`core/settings.py`；
